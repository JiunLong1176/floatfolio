Floatfolio

Personal investments dashboard

Static HTML mockup for a single-user portfolio tracker covering Moomoo (stocks), TNG e-Mas (gold) and Luno (crypto). Dark-default with a light toggle and live MYR ⇄ USD conversion across every monetary value.

01

Dashboard

Hero P/L, asset cards, today's movers, equity preview, allocation.
02

Holdings

Sortable table, asset-class filter chips, add-holding drawer, delete confirm.
03

History

Equity curve with cost basis, daily-P/L heatmap, range KPIs.
04

Settings

Account, Luno keys, gold spread, theme, danger zone.
05

Login

Magic-link sign-in card with idle & sent-confirmation states.

Notes

  • · Use the MYR/USD toggle in any header — every monetary number on the page reformats live.
  • · Theme preference and currency persist via localStorage.
  • · Sample data is realistic but static. Crypto would auto-sync via Luno's REST API in the real build.
  • · Floating P/L only — no fees or realised gains modelled.
